# MetaAutomate Community Code of Conduct

We want a professional community that welcomes contributors from diverse backgrounds, countries and experience levels, while working toward trustworthy and responsible automation.

## Expected behavior

Be respectful and constructive; discuss technical disagreements with evidence rather than personal attacks. Welcome beginners and explain decisions clearly. Attribute others' work, protect private data and respect the applicable laws and permissions of systems you test. Avoid stereotyping, harassment, exclusionary behavior and unwanted solicitation.

## Unacceptable behavior

Harassment, threats, discriminatory insults, sexual harassment, doxxing, sharing private conversations without consent, exposing another contributor's credentials, deliberately deceptive contribution claims, and sustained personal attacks are not acceptable.

Security vulnerability reports must be handled privately under SECURITY.md. This code of conduct is not authorization to access another user's accounts or data.

## Reporting and enforcement

Contact the repository maintainer @AhmadibOfficial privately when possible. Do not include sensitive personal information in a public issue. The maintainer may request edits, close discussions, temporarily limit participation or ban accounts from project spaces for serious/repeated violations. Reports should be handled with reasonable confidentiality, prompt consideration and an opportunity to respond when appropriate.

## Scope

This applies to project issues, pull requests, reviews, documentation, project chat channels and events where participants represent MetaAutomate.
