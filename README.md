# MetaAutomate

MetaAutomate is developing **Business Autopilot**: a way for businesses to turn operational objectives into controlled workflows and inspect evidence of their results. The first product demonstration focuses on inventory and replenishment preparation.

Current source includes the authenticated Objective Workspace, deterministic digital maturity assessments, synthetic inventory previews, and a separate local **assess → plan → approve → simulate → verify** demonstration. Live customer execution remains subject to the existing Phase 01/02/03 NO-GO boundaries.

With the API dependencies installed, run `python3 scripts/business_autopilot_demo.py serve` and open http://127.0.0.1:8090. The demo needs no database, cloud account, AI subscription or customer data.

See the [demo runbook and seven-minute walkthrough](docs/product/BUSINESS_AUTOPILOT_DEMO.md) for scenarios, honest financial assumptions, offline evidence verification and the customer-validation work ahead. The [Objective Workspace guide](docs/workspace/README.md) covers the separate authenticated local planning application.
